CSV Data Cleaner 🧹📊  
A beginner-friendly Python project that cleans and analyzes messy CSV datasets.

🚀 Features
- Load any CSV file
- Detect missing values (NaN)
- Fill missing numeric values using mean
- Remove duplicate rows
- Filter rows based on conditions (e.g., age filter)
- Generate summary statistics (console output)
- Export cleaned dataset as a new CSV file

🛠️ Technologies Used
- Python
- pandas

📂 How It Works
1. Load a CSV file into a DataFrame
2. Check and handle missing values
3. Clean data using mean imputation
4. Remove duplicate rows
5. Filter rows based on user input (optional)
6. Generate statistical summary
7. Save cleaned data into a new CSV file

📊 Example Use Case
Useful for beginners learning data analysis or anyone needing quick CSV cleaning before analysis.

📁 Output
- cleaned_data.csv (final cleaned dataset)
